# MoE アイテム台帳

Master of Epic公式サイトのアイテムボックスをアカウント別に記録し、横断検索する非公式ブラウザ拡張です。

**Chrome版・Firefox版は各ブラウザのストアで公開しています。**

- [Chrome ウェブストア版](https://chromewebstore.google.com/detail/amhcpkmoefmdegoeokoffboimffodmbf?hl=ja)
- [Firefox Add-ons版](https://addons.mozilla.org/ja/firefox/addon/moe-%E3%82%A2%E3%82%A4%E3%83%86%E3%83%A0%E5%8F%B0%E5%B8%B3/)

**Firefox版は最新版が公開済みです。**  
Chrome版は現在、v0.1.5をストアへ申請・審査中です。審査完了まではChrome ウェブストアで以前のバージョンが配信される場合があります。

最新版をすぐ利用したい場合は、下記の手動導入用ZIPも利用できます。

## v0.1.5

v0.1.5では、検索結果から売りたいアイテムを選択し、売買用のtweetを作成する機能を追加しました。

- 検索結果から複数のアイテムをチェックして選択
- 「売買tweet生成」画面で販売個数・価格・補足を編集
- アイテム数が少ない場合はコピー可能なtweet用テキストを生成
- 文字数が多い場合は「MoE 売買リスト」を表形式の1枚のPNG画像として生成
- PNGはダウンロードしてtweetへ添付可能
- PNGの表には「アイテム名 / 個数 / 価格」を表示
- アカウント名やログインIDなどの情報は売買用出力へ含めません
- 価格は自由入力で、「応相談」などの文字列も使用できます
- tweetには `#masterofepic` を付けたテンプレートを生成します

tweetの文字数判定は、日本語・英数字・URL・絵文字などによる差を考慮し、文字数制限を超えにくいよう余裕を持って判定します。

## Chrome版のインストール

1. [Chrome ウェブストアの「MoE アイテム台帳」](https://chromewebstore.google.com/detail/amhcpkmoefmdegoeokoffboimffodmbf?hl=ja)を開き、「Chromeに追加」を押します。
2. 拡張機能メニューから「MoE アイテム台帳」をツールバーに固定します。
3. 公式サイトにログインしてアイテムボックスを開きます。既に開いている場合は再読み込みします。

### 手動導入版からストア版へ移行する場合

手動導入版の「設定・バックアップ」でJSONを保存してから、手動導入版を無効にし、ストア版をインストールしてください。

ストア版の「設定・バックアップ」でJSONを復元し、内容を確認してから不要になった手動導入版を削除します。

保存データは別の拡張機能IDへ自動では引き継がれません。

## Firefox版のインストール

[Firefox Add-onsの「MoE アイテム台帳」](https://addons.mozilla.org/ja/firefox/addon/moe-%E3%82%A2%E3%82%A4%E3%83%86%E3%83%A0%E5%8F%B0%E5%B8%B3/)から通常のアドオンとしてインストールできます。

Firefox 140以降が対象です。

最新版は **v0.1.5** です。

- [Chrome / Edge用 ZIP](https://github.com/sincostanrap-droid/moe-item-ledger/raw/refs/heads/main/dist/moe-ledger-chrome-v0.1.5.zip)
- [Firefox用 ZIP（未署名）](https://github.com/sincostanrap-droid/moe-item-ledger/raw/refs/heads/main/dist/moe-ledger-firefox-v0.1.5.zip)

## Chrome / Edgeへの手動導入

1. 上のChrome / Edge用ZIPをダウンロードし、任意の場所へ展開します。
2. Chromeは `chrome://extensions`、Edgeは `edge://extensions` を開きます。
3. 「デベロッパーモード」をONにします。
4. 「パッケージ化されていない拡張機能を読み込む」を選び、展開した `manifest.json` のあるフォルダを指定します。
5. 拡張機能メニューから「MoE アイテム台帳」をツールバーに固定します。
6. そのブラウザで公式サイトにログインしてアイテムボックスを開きます。既に開いている場合は再読み込みします。

## Firefoxへの手動導入

通常はFirefox Add-ons版の利用を推奨します。

手動導入する場合は以下の手順です。

1. 上のFirefox用ZIPをダウンロードします。
2. `about:debugging#/runtime/this-firefox` を開きます。
3. 「一時的なアドオンを読み込む」でZIPを選択します。展開して `manifest.json` を選ぶ方法でも導入できます。
4. 公式サイトのアイテムボックスを開くか再読み込みします。

一時インストールした拡張機能はFirefox再起動時に解除されるため、再起動後は再度読み込む必要があります。

## 使い方

- アイテムボックスを開くと、表示中のページを自動取得します。
- 初めて検出したアカウントは登録欄が出ます。ログインIDは任意で、未入力でも利用可能です。
- 拡張の「アイテム検索」で保存済みの全アカウントを検索します。
- 列見出しを押すと、名前・アカウント・ID・個数・更新日時の昇順／降順を切り替えます。
- 「大きな画面で開く」で別タブの一覧を開けます。
- 「アカウント」でIDの編集、各ページの取得日時・未取得状態を確認できます。
- 「設定・バックアップ」で自動取得の切り替え、JSONの保存・復元ができます。
- アイテム検索から検索結果または全件をCSV保存できます。
- 売りたいアイテムをチェックし、「売買tweet生成」から売買用テンプレートを作成できます。
- 販売個数、価格、補足は生成画面で編集できます。
- tweetに収まりやすい場合はテキストとしてコピーできます。
- アイテム数が多い場合などは、一覧を1枚のPNG画像として生成できます。

## 在庫の更新ルール

アカウント名＋ページ番号で在庫を置き換えます。繰り返し取得しても二重計上されず、そのページから消えたアイテムは記録から消えます。取得失敗時は古い記録を残します。

基本枠とレンタル枠は独立しています。レンタル枠は各ページを開いて取得してください。開いていないページの在庫は古いままです。未契約ページは無理に開く必要はありません。

検索とCSVでは同名の品を全アカウント横断で1行に合算し、各アカウント名と所持数を併記します。アカウント絞り込み時は対象アカウント分のみ合算します。

複数ページ分を合算した行の更新日時は最も古い取得日時で、「アカウント・ページ別日時」から内訳を確認できます。日時はゲーム内での入手・移動日時ではありません。

## 更新方法

Chrome ウェブストアまたはFirefox Add-onsからインストールした版は、ストア経由で更新されます。

Chrome版は新バージョンを申請した直後、審査完了まで以前のバージョンが配信される場合があります。

以下は手動導入版の更新手順です。

バックアップを保存後、新しいZIPのファイルを同じ展開先に置き換え、拡張管理画面で拡張を再読み込みし、公式アイテムボックスも再読み込みします。

手動導入版に自動更新はありません。ブラウザ間の自動同期もありません。別の導入方法へ切り替える場合は必要に応じてJSONを復元してください。

## 制限

- HTTPSの `moepic.com` / `www.moepic.com` の `/mp_itembox/mp_itembox.php` が対象です。
- 128行・6列とページ番号1〜4を確認できないページは保存しません。
- アカウント表示名で識別するため、名前の変更は別アカウントとして扱います。
- ゲームの転送・削除・整理操作、自動ログイン、アカウント切り替え、全ページ巡回は行いません。
- 契約終了したレンタル枠も以前の記録が残る場合があります。取得日時を確認してください。
- 公式サイトの構造変更で取得できなくなる可能性があります。

## プライバシー

保存先はブラウザ内です。拡張機能から外部サーバーへデータを送信しません。パスワード・Cookie・ページの不透明な識別文字列は保存しません。

売買tweet・PNG生成時も、アカウント名やログインIDなどの管理用情報は出力しません。

詳しくは [プライバシーポリシー](PRIVACY.md) をご覧ください。

## 開発・テスト

`common/` が共通ソース、`chrome/`・`firefox/` が読み込み用です。

`python scripts/package.py` で共通ソースを両版へ反映し、各 `manifest.json` のバージョン番号を使用して配布ZIPを再作成できます（Python 3が必要）。

```text
python scripts/package.py

node tests/search.cjs
node tests/unit.cjs tests/fixture.html
```

Node.jsと `python` コマンドで動作するPython 3が必要です。`fixture.html` は架空データです。実アカウント・個人在庫を含みません。

`tests/test.cjs` はPlaywright用のブラウザ試験コードです。実行にはPlaywrightと対応するChromiumが別途必要です。
